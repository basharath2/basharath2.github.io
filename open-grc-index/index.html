How the index works

  • Listing is free and cannot be bought. Entries are alphabetical everywhere; there are no “best” lists.
  • Every fact has a public source and a check date. A feature such as an MCP server, an API or an Arabic edition shows as yes only when the maintainer documents it. Unknown does not mean no.
  • Brivellis Editorial writes the summaries in its own words. Summaries supplied by a maintainer are marked.
  • Resources made by Brivellis are labelled House, meet the same rules and are never placed above others.
  • Standards are named by designation only. The index does not reproduce standards text, certify anything or endorse what it lists.

Read the listing rules

Register a resource

Maintainers register on GitHub with a short form. We collect no email address and run no form of our own.

  1. Check the resource is free to use, relevant to a framework above, maintained, and respects copyright.
  2. Open a registration issue on GitHub and fill in the form, or open a pull request with one entry file.
  3. Brivellis Editorial reviews it against the listing rules. We aim to answer within 7 days and give the reason for any refusal.
  4. Once listed, you can show the badge on your README or site.

To correct or remove an entry, open a correction issue in the same repository. Removal requests from a maintainer are always honoured.
